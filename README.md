# Boris Engineering & Construction Ltd — Website

Boris Engineering & Construction Ltd is a Nigerian engineering and construction company delivering quality, durable, and innovative building, civil, and renovation solutions.



## Getting started

```bash
npm install
cp .env.example .env.local   # fill in the values — see "Environment variables" below
npm run dev                  # http://localhost:3000
npm run build                # production build
npm run start                # run the production build
```

Requires Node 18.18+ (Next.js 16 / React 19). The site builds and runs
fine with `.env.local` empty — Sanity falls back to placeholder content,
and quote submissions are logged to the console instead of saved/emailed,
so you can develop locally before any of the three services are set up.
